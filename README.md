# Software and Networking Labs

Three hands-on exercises covering Java, network configuration and project planning.

| Lab | What it covers |
| --- | --- |
| [Connect Four](java/Puissance4.java) | A two-player Java console game with gravity, win detection and draws |
| [Packet Tracer](networking/) | IPv4 addressing, static routing and an extended ACL policy |
| [GanttProject](planning/) | A mobile application delivery plan with 17 tasks and 14 dependencies |

## Run Connect Four

Use JDK 21 and run from the repository root.

```sh
java java/Puissance4.java
```

Enter a column from 1 to 7. Two players take turns until a player lines up four pieces or the grid fills.
